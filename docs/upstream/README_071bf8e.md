## Abstract

TokenLeak is the first systematic framework for reconstructing private prompts from transformer inference engines through the fusion of inter-token timing signals and last-level cache access patterns. The framework employs three independent agents (Timing Oracle Agent, Cache Profiler Agent, Token Reconstructor Agent) and a novel metric, the **Token Reconstruction Confidence Score (TRCS)**, achieving 73.4% Top-1 and 91.2% Top-5 token reconstruction accuracy on GPT-2 under zero-noise simulation. Combined defenses (differential privacy + cache-oblivious access) reduce attack accuracy to 18.7% at 4.1% latency overhead.

## How to Reproduce

### 1. Build the PDF

```bash
bash scripts/build.sh
```

Requires [tectonic](https://tectonic-typesetting.github.io/) — packages downloaded automatically.

### 2. Run the Simulation

```bash
pip install -r requirements.txt
python -m src.evaluation.evaluate
```

Results appear in `data/results/accuracy_vs_noise.csv`. All experiments use `seed=42`.
